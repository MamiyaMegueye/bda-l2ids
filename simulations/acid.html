La transaction SQL

UPDATE compte
SET solde = solde - 5000
WHERE titulaire = 'vous';
UPDATE compte
SET solde = solde + 5000
WHERE titulaire = 'ami';
COMMIT;

    Bases de données avancées · L2 IDS · SupNum — Le modèle BASE
    Les trois propriétés BASE
    BA

    Basically Available — disponibilité de base

    Le système privilégie la disponibilité.

    S

    Soft State — état souple

    L’état peut évoluer pendant la synchronisation.

    E

    Eventually Consistent — cohérence à terme

    Les copies finissent par converger, sous les conditions appropriées.

    Note : BASE est une approche de conception des systèmes distribués, pas une propriété obligatoire de toutes les bases NoSQL. Elle n’est pas l’opposé strict d’ACID : beaucoup de systèmes combinent les deux selon les opérations.
